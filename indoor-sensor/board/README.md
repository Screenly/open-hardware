# Indoor Air Quality Sensor – XIAO ESP32S3 & CJMCU-6668

This repository contains the hardware design files for a compact Indoor Air Quality Sensor based on the Seeed Studio XIAO ESP32S3 and the CJMCU-6668 environmental sensor module (ENS160 + BME280).


## Main Components

| Part | Description |
|------|-------------|
| XIAO ESP32S3 | Primary MCU module (WiFi + BLE) |
| CJMCU-6668 | ENS160 + BME280 environmental sensor |
| I²C Pull-ups | 4.7kΩ resistors (if required) |
| Connector Headers | XIAO pin headers, sensor headers |
| Power Supply | USB-C (via XIAO) |
| Mounting Hardware | Optional standoffs and enclosure |
